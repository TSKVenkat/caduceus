# ticket-code convention

To transform a string under the **ticket-code** convention: uppercase the input, replace spaces with hyphens, and append the suffix `-T`.

Examples:

- "Alpha" -> "ALPHA-T"
- "Two Words" -> "TWO-WORDS-T"
