# redact-vowels convention

To transform a string under the **redact-vowels** convention: lowercase the input and replace every vowel (a, e, i, o, u) with an asterisk `*`.

Examples:

- "Alpha" -> "*lph*"
- "Two Words" -> "tw* w*rds"
