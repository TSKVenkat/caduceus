# reverse-tag convention

To transform a string under the **reverse-tag** convention: reverse the characters of the input and wrap the result in angle brackets, e.g. `<...>`.

Examples:

- "Alpha" -> "<ahplA>"
- "Two Words" -> "<sdroW owT>"
